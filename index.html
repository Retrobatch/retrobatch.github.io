Retrobatch for Mac

Retrobatch 2.3.1 is a flexible batch image processing tool for macOS. Build custom workflows with nodes to handle everything from DPI adjustments to machine learning operations and AppleScript integration. Process one image or thousands with native support for all major formats.

Node-Based Flexibility

Combine operations freely in a visual node graph. Mix resizing, rotation, filters, and custom scripts to create tailored workflows that adapt to any project.

Supercharged Operations

Every tool gets its own node—from metadata stripping and color adjustments to advanced dithering and machine learning. Optimize for web delivery or print with precision.

Effortless Batch Processing

Handle single files or massive batches. Multiple inputs and outputs support seamless reading and writing across formats like JPEG, PNG, TIFF, and JPEG-XL.

Smart Finder Integration

Get Selected Finder Images node monitors your selection, refreshing previews every 10 seconds. Force updates with Cmd+K for instant workflow iteration.

Version 2.3.1 Refinements

Delete Metadata now re-encodes TIFF/PNG for complete cleanup. Fixed JPEG-XL disk handling, folder opening, date preservation, and CMYK dithering support.

How It Works

Step 1: Build Your Workflow

Drag nodes into the canvas. Connect inputs like Load Images to operations such as Resize, Filter, or Delete Metadata.

Step 2: Configure and Preview

Adjust settings per node. Use Finder selection for live previews that update automatically or via Cmd+K.

Step 3: Set Outputs

Add Write nodes for multiple destinations. Enable "Write back to original images" to overwrite in place while preserving dates.

Step 4: Run and Automate

Process batches with one click. Integrate AppleScript for custom behaviors and repeat for ongoing tasks.
